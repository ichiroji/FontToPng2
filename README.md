# FontToPng2

フォントの文字を1文字ずつ PNG 画像に書き出す Windows 用ツールです。
ゲームなどで使うビットマップフォント素材の作成を想定しています。カラー絵文字にも対応しています。

## 主な機能

- インストール済みフォント、またはフォントファイル（TTF / OTF / TTC）を指定して変換
- 出力する文字をチェックボックスで選択（英数字、記号、ひらがな・カタカナ、漢字、全角英数・半角カナ、絵文字）
  - 任意のコードポイント範囲や、文字の直接指定・テキストファイル読み込み（文字コード自動判別、重複除去）も可能
- カラー絵文字（COLRv0 / CBDT / sbix 形式）の出力。ZWJ シーケンス（👨‍👩‍👧）や肌の色の指定（👍🏽）、国旗も1枚の画像に
- 透明背景または背景色の指定、文字色、余白、上下のトリム、文字の形に合わせた切り抜き
- フォントに無い文字、描くと空白になる文字の自動スキップ
- 出力した文字の一覧を CSV で出力
- SDF済み画像（Yuka2 用。文字を最大8倍で描いてから距離値にしたグレースケール画像）での出力
- プレビュー表示、設定の自動保存

## 動作環境

- Windows 10 / 11
- [.NET 10](https://dotnet.microsoft.com/) ランタイム（ビルドには .NET 10 SDK）

## ビルドと実行

```
git clone https://github.com/ichiroji/FontToPng2.git
cd FontToPng2
dotnet run --project src/FontToPng2.App
```

Visual Studio 2022 以降で `FontToPng2.slnx` を開いてビルドすることもできます。

## 出力形式

### 画像ファイル

1文字につき1枚の PNG を出力します。ファイル名は Unicode コードポイントの16進数（小文字、ゼロ埋めなし）です。

| 文字 | ファイル名 |
|---|---|
| `A` | `41.png` |
| `あ` | `3042.png` |
| `👨‍👩‍👧`（複数のコードポイント） | `1f468-200d-1f469-200d-1f467.png` |

### 一覧 CSV

出力した文字の一覧を CSV で出力します（UTF-8・BOM なし、改行 CRLF、ヘッダー行なし）。

```
文字コード番号,ファイル名[,画像の種類[,余白]]
```

- 文字コード番号は `0x` 付きの16進数。複数のコードポイントからなる文字は `:` でつなぎます
- ファイル名の前には任意の文字（フォルダ名など）を付けられます
- 3列目は画像の種類で、通常の単色の画像では省略されます
  - `1` … カラーの字形
  - `2` … SDF済み画像（後述）。4列目は上下左右の余白(px)

```
0x41,FONT\41.png
0x1f600,FONT\1f600.png,1
0x1f468:0x200d:0x1f469:0x200d:0x1f467,FONT\1f468-200d-1f469-200d-1f467.png,1
```

### SDF済み画像（Yuka2 用）

「SDFで出力（Yuka2用）」をオンにすると、単色の文字を SDF（Signed Distance Field）済みの画像で出力します。
ゲームエンジン Yuka2 がそのまま読み込み、拡大・太さ・縁取りに使います（仕様の正本は Yuka2 の `Document/SDF済み画像フォント仕様.md`）。

- 画像は 8bit グレースケールの PNG で、画素の値は文字の輪郭からの符号付き距離（内側が明るい。境界 = 128）
  - 距離 d(px) を `t = 0.5 + d / (2 × spread)` で 0〜1 にし、`t × 255` を丸めて格納します
- セル（送り幅 × 文字高）は通常の出力と同じで、その上下左右に余白を付けます
  - spread = 文字高 × 0.25、余白 = ceil(spread)。どちらも全文字で同じ値です
- 文字を「倍率」（1 / 2 / 4 / 8、既定 4）倍の大きさで描いてから距離値にするので、輪郭がなめらかになります
- カラーの字形は従来どおりの画像（透明背景）で出力し、CSV は `,1` になります
- 文字色・背景色・余白・文字の形に合わせた切り抜きの設定は使いません（上下のトリムは使えます）

```
0x41,FONTSDF\41.png,2,24
0x1f600,FONTSDF\1f600.png,1
```

## カラー絵文字フォントについて

描画に使っている SkiaSharp（Windows 版）の制限で、フォントの形式によってはカラー絵文字を描画できません。

| 形式 | 例 | 結果 |
|---|---|---|
| COLRv0 | Segoe UI Emoji（Windows 標準） | カラーで描画（国旗はフォントに含まれない） |
| CBDT / sbix | [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) の `NotoColorEmoji.ttf` | カラーで描画（国旗も可） |
| COLRv1 | Noto Color Emoji の COLRv1 版 | 描画されない（空白） |
| SVG | EmojiOne Color など | 白黒になる |

描画できない形式のフォントを選ぶと、プレビューの下に警告が表示されます。

## 設定ファイル

設定は `%APPDATA%\FontToPng2\settings.json` に保存されます。削除すると初期設定に戻ります。

```
src/

```
